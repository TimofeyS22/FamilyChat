# Local Snapshot Recovery

On 2026-10-09, the project was recovered into a separate local directory from
Cursor's local Git object archive and its published baseline index. The index
publication timestamp is 2026-07-20T18:11:50Z. The original Desktop directory was
preserved without changes.

The original project contained iCloud `dataless` files whose contents could not
be downloaded because no active iCloud Drive account was available. Recovery
does not restore the iCloud account or its private runtime data.

## Verification

- All 243 project files were recovered; no project paths were missing.
- Recovered paths and byte sizes match the current original directory metadata.
- All 24 readable original project files match their recovered Git blob hashes.
- Every extracted snapshot file was checked against its Git blob hash.
- 111 original paths have modification timestamps newer than the index entries.
  Their sizes match, but unavailable contents cannot be compared byte for byte.

This is a complete recovered snapshot. It is not proof that every recovered file
is identical to the latest cloud version. Once cloud access returns, compare the
two directories and preserve any newer changes before replacing either copy.

## Exclusions

Private `.env` files, signing material, local databases, browser state, caches,
dependencies, build outputs, and the original `.git` internals were not recovered
into the publishable project. Configure new private runtime credentials before
starting a stack. Existing stage validation gaps remain as documented in the
roadmap and runbooks; recovery does not close those gaps.

## Checks After Recovery

- Frontend: 125 tests, TypeScript checking, and production build passed.
- Backend: 89 tests passed with one existing Starlette deprecation warning.
- Frontend lint reports two errors in `call-overlay.tsx` and `chat-shell.tsx`
  and one hooks dependency warning.
- Backend lint reports three long lines in `app/services/admin.py`.
- Backend format checking reports `app/core/config.py` and
  `app/services/admin.py` require formatting.
- Default secret scanning found only the explicitly verified public
  `test-invite-pepper-with-at-least-32-bytes` fixture in tests/setup examples.
  That exact fixture was allowed for the final scan; private runtime secrets
  remain excluded.

These existing lint findings were preserved to keep recovery separate from
application changes. Passing tests and a build do not prove live browser flows.
